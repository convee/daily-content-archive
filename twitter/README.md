# X / Twitter 归档

## 采集范围

使用用户已登录的本地浏览器，只读采集 AI、开发者工具和前沿科技内容。范围由 `sources.json` 明确定义，包括官方机构、研究者/工程师、主题搜索，以及用户首页的“正在关注”和“为你推荐”；不是对整个平台的全量镜像。

每两小时读取各账号时间线并向下滚动到已提交检查点之前。帖子以 status ID 去重；高信号帖子继续打开回复和引用页，保存能补充技术细节、数据、反例、一手使用反馈或风险判断的回复。

“正在关注”作为连续来源：每次从最新内容向下滚动，直到越过该信息流已提交的检查点。“为你推荐”由算法动态排序，无法证明时间段全量，因此作为发现来源：每次保存可见快照、按 status ID 去重，并在运行日志记录滚动批次、首末帖子和采集时间。账号清单与主题搜索继续承担稳定覆盖，避免只依赖推荐算法。

若登录失效、页面限流、验证码、账号不可见或评论加载不全，则不推进对应来源检查点，写入运行日志并通过钉钉告警。任务绝不点赞、转发、回复或关注。
