## 6. Python 的 `str.lower()` 为什么会成为安全漏洞

- HN item：`49440410`
- 热度快照：139 points / 60 comments
- 原文：[Seth Larson](https://sethmlarson.dev/when-str-lower-is-a-security-vulnerability)
- 讨论：[Hacker News](https://news.ycombinator.com/item?id=49440410)

IDNA 2003 / StringPrep 依赖 Unicode 3.2 的固定大小写折叠规则，但 `str.lower()` 会随 Python 自带的新版 Unicode 数据变化。安全协议中的文本规范化必须版本固定，不能调用看似等价的通用 API。对应 CVE-2026-17084。
